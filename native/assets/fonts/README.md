# Bundled UI fonts

Inter (body, 400 and 600) and Sora (display, 650) are distributed under the
SIL Open Font License 1.1. Their licenses and copyright notices are included
here and copied into the release notice bundle.

Sources: `https://github.com/google/fonts/tree/main/ofl/inter` and
`https://github.com/google/fonts/tree/main/ofl/sora`.
The included TTFs were instantiated from the variable fonts and subset to
Latin/extended Latin, punctuation, currency and arrows using fontTools 4.60.1.
Inter's optical-size axis uses the upstream default. The files are embedded in
the executable; no font download or system installation occurs at runtime.
