O mesmo percurso simples, do princípio ao fim.

ANTES DE COMEÇAR

Alguma dúvida?

De que preciso para usar a aplicação?+

De um computador Windows 10/11 de 64 bits com Internet, um leitor de cartões PC/SC compatível com os drivers instalados e o teu cartão Navegante. A aplicação é nativa e não precisa de navegador ou de instalar runtimes.

Posso carregar o passe neste site?+

O carregamento real é feito na aplicação Windows, que comunica com o leitor ligado ao teu computador. A demo online usa apenas dados fictícios e não efetua cobranças ou alterações no cartão.

A aplicação é gratuita?+

O download é gratuito. Os títulos e o saldo de transporte têm os valores apresentados pelos serviços oficiais. Pagamento e gravação no cartão são passos diferentes; aguarda sempre a confirmação final.

Esta é uma aplicação oficial?+

Não. Este é um projeto independente, sem afiliação à TML.

Funciona em Mac, Linux ou no telemóvel?+

A aplicação distribuída suporta Windows 64 bits. Podes explorar a demo no navegador noutros dispositivos, mas esta não carrega cartões reais.
